## 김정우 · Backend Developer

결제 도메인 4년차 백엔드 개발자입니다. PG·선불전자지급 영역에서 결제·충전 API부터 정산·세금계산서·회계연동 배치, 원천사 연동, 관리전산까지 결제 시스템 전 구간을 설계·개발해왔습니다.

Spring Batch 기반 정산·회계연동 배치를 다수 단독 구축했고, 금융감독원·금융결제원 심사 대응과 개인정보 마스킹·암호화 같은 금융권 컴플라이언스 요건을 실제 운영 시스템에 반영했습니다. 장애가 없는 코드보다 **장애가 나도 복구되는 구조**를 만드는 데 집중합니다.

### (주)티엔씨테크놀로지

PG·선불전자지급 결제 플랫폼의 신규 구축과 운영 고도화를 담당합니다.

- 크림페이·Kovan 선불전자지급 플랫폼을 원천사 연동부터 정산·증빙까지 구축
- Spring Batch·Quartz 기반 정산·세금계산서·전표 회계연동 배치 단독 개발
- 금융결제원·헥토파이낸셜 등 대외기관 연동과 연동규격서(OpenAPI) 설계·배포
- 이기종 결제 모듈 거래 중계 계층으로 발급·취소 인터페이스 표준화
- 금융감독원 실사·금융결제원 심사 대응, 개인정보 마스킹·암호화 적용

### (주)헬로핀테크

대출 중개 서비스의 정산·결제·서류 자동화 백엔드를 담당했습니다.

- 정산 프로세스를 MySQL 프로시저에서 Java로 전환하고 테스트 체계 도입
- 가맹점 정산 데이터를 자동 취합하는 Spring Batch 배치와 백오피스 구축
- 정부24 연동 기반 비대면 대출 서류 제출 자동화와 재처리 로직 구현
- MyBatis → Spring Data JPA 마이그레이션, Spring Security·AOP 표준화
