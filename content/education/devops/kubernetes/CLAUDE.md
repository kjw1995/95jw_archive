## 문체 규칙

1. **도입부**: 앞 장을 한두 문장으로 되짚고(`[NN. 제목](../NN-slug)` 링크), 이 장의 **원리 2~3개**를 굵게 세운다. 각 절은 그 원리를 되짚으며 "첫째 원리다", "둘째 원리의 ~이다"처럼 잇는다.
2. **모든 표에 "왜" 열**(왜 그런가, 왜 나눴나, 왜 필요한가)을 둔다. 비교 표도 마찬가지다.
3. **개념 위주로 상세하게.** "이 PC에서 ~를 확인했다", "실측", "검증하지 못한 것" 같은 특정 환경의 실험 기록 화법은 쓰지 않는다(06장부터 적용, 01~05는 제거함). 동작을 설명할 때는 "~하면 ~가 된다", "예를 들어 다음처럼 보인다"처럼 일반적으로 쓰고, 예시 출력의 노드 이름·IP는 `node-1`, `192.0.2.10` 같은 예시 값을 쓴다.
4. **원문의 낡은 서술은 현재 버전 기준으로 검증해 정정**한다(쿠버네티스 1.34 이상 기준, 공식 문서·feature gate 페이지·릴리스 노트·프로젝트 README로 확인). 정정한 내용은 커밋 메시지에 적는다.
5. **구조 유지**: `## N. 제목` 절 번호와 순서, 표, callout, 마지막의 `## 핵심 정리`(번호 없음) 표와 `**용어 정리**` info callout. 원문에 없던 중요한 개념(예: 네이티브 사이드카, Gateway API 채널)은 절이나 소절을 더한다.
6. **코드 블록은 전부 40자 폭 이내**(한글은 2칸). 언어 없는 블록도 같다. 긴 명령은 `\`로 줄을 나누고, 긴 URL·키는 변수나 본문 인라인 코드로 뺀다. 40자를 넘는 필드 이름(`requiredDuringSchedulingIgnoredDuringExecution` 등)은 info callout으로 줄임 표기(`required…Execution`)를 선언하고 YAML에 줄여 쓴다. 긴 YAML 값은 다음 줄로 접는다(`apiVersion:` 다음 줄에 값).
7. **링크**: 같은 디렉터리는 `../NN-slug`, 다른 시리즈는 페이지 URL 기준 상대 경로(`../../../network/30-dns-server-structure`, `../../../architecture/restful/01-basics`). 앞 장이 "N장에서 본다"고 미뤄 둔 질문은 그 장의 도입에서 받아 준다.
8. **callout 타입**은 info, warning, error, important만 쓴다(tip 없음).
9. **커밋 메시지**는 루트 CLAUDE.md 형식(한 줄 요약 + `수정`/`생성`/`삭제` 항목)이고, 정정한 사실과 보강한 개념을 항목으로 적는다. 커밋 후 바로 `git push origin main`.

## 절차

1. 원문 전체를 읽는다. `grep -n "NN장\|NN-slug" content/education/devops/kubernetes/*.md`로 다른 장이 이 장에 미뤄 둔 참조를 모으고, 앞뒤 장의 `## ` 제목으로 링크 대상을 정한다.
2. 낡았을 만한 서술(버전, 제거된 기능, deprecated 명령)을 공식 문서로 확인한다.
3. 초안을 저장소 밖(임시 디렉터리)에 쓴다.
4. `tools/chapter-pipeline.sh <초안> content/education/devops/kubernetes/NN-slug.md <커밋메시지파일>`을 실행한다. 폭·링크·표·callout·금지 표현("이 PC") 검사를 통과해야 설치(CRLF)와 커밋이 된다. 검사만 하려면 `node tools/check-chapter.js <파일> --links-as <대상 경로>`.
5. 가능하면 로컬 Hugo 빌드(`hugo --gc`)로 페이지가 렌더링되는지, 이전/다음 링크가 이어지는지 본다.
6. 사용자에게 변경 요약(세운 원리, 정정한 내용, 보강한 개념)을 한국어로 보고한다.

## 환경 메모

- content 파일의 줄 끝은 Windows 체크아웃에서 CRLF다(autocrlf). 저장소 blob은 LF이므로 **macOS·Linux(autocrlf 미설정)에서는 `--install` 대신 초안을 그대로 복사하고 `--crlf` 없이 재검사한 뒤 커밋**한다. 그대로 파이프라인을 돌리면 CRLF blob이 커밋된다. macOS의 `sed -i`는 `-i ''`가 필요하므로 파이프라인은 sed 대신 node를 쓴다.
- 사용자 메시지가 "챕터 NN 진행해"처럼 시리즈 없이 오면 이 시리즈다. 다른 시리즈의 같은 번호(동시성 08 등)와 헷갈리지 않게 대상 경로를 한 줄로 확인하고 시작한다.
- 클러스터가 없는 기기에서도 셸 조각은 검증할 수 있다. `kubectl(){ printf '[%s]' "$@"; echo; }`처럼 인자를 찍는 가짜 함수를 두고 bash와 zsh에서 돌려, 변수로 이어 붙인 쿼리가 의도대로 조립되는지 본다. zsh에서는 `$S[*]`가 첨자로 읽히므로 `${S}[*]`로 적는다. jq 식은 예시 JSON으로 돌려 본다.
- 동작 확인이 필요하면 Docker 위 k3s(`rancher/k3s`) 컨테이너로 임시 클러스터를 띄워 본다(선택 사항). 확인 결과는 본문에 실험 기록으로 쓰지 않고 일반적인 사실로만 반영한다.
